连接配置

只需部署一次本站点，以下 R2 信息在此填写并保存于本机浏览器。 令牌请从 Cloudflare 控制台 R2 → 创建 API 令牌 获取。

把电脑上「导出配置」得到的 .json 文件内容整体复制粘贴到这里，再点「执行导入」。

连接失败？最常见原因是存储桶 CORS 未配置或配置有误。 请到 Cloudflare 控制台 → R2 → 你的桶 → Settings → Public bucket access → CORS， 按下面这段配置（把 AllowedOrigins 换成你当前访问本站的域名， 不要带结尾斜杠，且必须包含 AllowedHeaders: ["*"]）： 
[
  {
    "AllowedOrigins": ["（当前站点域名）"],
    "AllowedMethods": ["GET", "HEAD", "PUT", "POST", "DELETE"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]

其中 ExposeHeaders: ["ETag"] 用于大文件分片上传（浏览器需要读到每个分片的 ETag 才能合并；缺失时自动降级为整包上传）。
